## Hard Trading Constraints (apply to all roles)

- **Evaluation anchor:** Fixed 2026-05-04 close baseline (SPY 718.01). Never revert to a funded-date baseline.
- **Concentration caps:**
  - QQQ max 45% of equity
  - Any single stock max 15% of equity
  - Any ETF (non-QQQ) max 20% of equity
- **PDT awareness:** If `daytrade_count >= 3`, or Alpaca already rejected a same-day closing order today, do not write intraday `SELL` lines for positions opened today.
- **No after-hours / pre-market trading:** Only regular-session orders.
- **Gross exposure target band:** 60–90% during offensive catch-up; 30–50% during defensive.
- **UNIVERSE GATE — CODE ENFORCED:** The Alpaca CLI tool `submitOrder` REJECTS any BUY order for a symbol not in the approved universe (AVGO, EIS, GLD, GOOG, HOOD, META, NVDA, QQQ, QTUM, RKLB, SHLD, SOXX, VOO, ARKX). Do NOT attempt to bypass this gate with direct API calls or dashboard endpoints.
- **24-HOUR COOLDOWN:** Do NOT re-buy any symbol that was sold within the previous 24 hours unless a fresh hourly note explicitly authorizes re-entry. This applies even if the price looks attractive.
- **ANTI-CHURN HARD STOP:** Do NOT execute a same-day round trip (buy then sell, or sell then buy) in the same symbol within a single trading session. If a symbol was bought today, you may NOT sell it today unless the hourly note explicitly authorizes the exit. If a symbol was sold today, you may NOT buy it back today.
- **SYMBOL BAN GATE — CODE ENFORCED:** `memory/.trading_lock.json` may contain a `bannedSymbols` array. The Alpaca CLI tool `submitOrder` and the universal SDK factory `createOrder` REJECT any BUY order for a symbol listed in `bannedSymbols` unless the order is explicitly allowed via the `allowed` field. Hourly strategist controls `bannedSymbols`; tactical agent cannot override it.
- **TURNOVER BUDGET:** Max 2 position-changing trades per trading day and max 20% of equity gross weekly turnover (buys + sells). Compliance-cleanup exits and hourly-authorized protective exits are exempt. When the budget is spent, no further discretionary trades that day.
- **NO FULL LIQUIDATIONS:** Exiting the entire portfolio, or a full core ETF position (QQQ, VOO, SOXX) within one session, is prohibited except for compliance-breach cleanup of a specific unauthorized position. De-risk by stepping the exposure band down gradually (max 15 pp per day).
- **CORE ETF STOP FLOOR:** No stop-loss trigger on QQQ, VOO, or SOXX tighter than 8% below current price. Single-name stops at least 6% below entry unless a documented binary event within 48h justifies tighter.
- **CASH TARGET:** In neutral/offensive regimes, cash above 10% of equity for two consecutive hourly runs requires either a deployment order or a written concrete blocker; "staying selective" is not a blocker.
- **ORDER PATH LOCK:** All orders go through `bun run src/tools/alpaca_cli.ts submit-order`. Direct Alpaca REST/SDK calls, `bun -e`/`curl`/`fetch` order submission, reading broker credentials from the environment, and editing lock files or guard code by the tactical agent are prohibited and treated as critical breaches.
