## Hard Trading Constraints (apply to all roles)

- **Evaluation anchor:** Fixed 2026-05-04 close baseline (SPY 718.01). Never revert to a funded-date baseline.
- **Concentration caps:**
  - QQQ max 45% of equity
  - Any single stock max 15% of equity
  - Any ETF (non-QQQ) max 20% of equity
- **PDT awareness:** If `daytrade_count >= 3`, or Alpaca already rejected a same-day closing order today, do not write intraday `SELL` lines for positions opened today.
- **No after-hours / pre-market trading:** Only regular-session orders.
- **Gross exposure target band:** 60–90% during offensive catch-up; 30–50% during defensive.
- **UNIVERSE GATE — CODE ENFORCED:** The Alpaca CLI tool `submitOrder` REJECTS any BUY order for a symbol not in the approved universe (AVGO, EIS, GLD, GOOG, HOOD, META, NVDA, QQQ, QTUM, RKLB, SHLD, SOXX, VOO, ARKX). Do NOT attempt to bypass this gate with direct API calls or dashboard endpoints.
- **24-HOUR COOLDOWN:** Do NOT re-buy any symbol that was sold within the previous 24 hours unless a fresh hourly note explicitly authorizes re-entry. This applies even if the price looks attractive.
- **ANTI-CHURN HARD STOP:** Do NOT execute a same-day round trip (buy then sell, or sell then buy) in the same symbol within a single trading session. If a symbol was bought today, you may NOT sell it today unless the hourly note explicitly authorizes the exit by including the exact substring `AUTHORIZE SAME-DAY SELL <SYMBOL>` in `memory/todo.md`. The code-level parser guard checks for this exact phrase; "explicitly authorizes" alone is not sufficient. If a symbol was sold today, you may NOT buy it back today.
- **SYMBOL BAN GATE — CODE ENFORCED:** `memory/.trading_lock.json` may contain a `bannedSymbols` array. The Alpaca CLI tool `submitOrder` and the universal SDK factory `createOrder` REJECT any BUY order for a symbol listed in `bannedSymbols` unless the order is explicitly allowed via the `allowed` field. Hourly strategist controls `bannedSymbols`; tactical agent cannot override it.
- **NO TOTAL LIQUIDATION WITHOUT AUTHORIZATION:** The tactical agent may NOT sell the last/only remaining shares of more than one symbol in a single tactical cycle, and may NOT reduce gross exposure below 30% unless (a) the event detector flags a CRITICAL broad-market event, or (b) the hourly note explicitly authorizes a portfolio-wide de-risking. Going from 60% gross exposure to 0% in one cycle is prohibited.
- **DAILY TRADE BUDGET:** The tactical agent may place at most 3 filled orders per day without fresh hourly authorization. If the day already has 3+ filled orders, default to hold-only until the next hourly cycle.
